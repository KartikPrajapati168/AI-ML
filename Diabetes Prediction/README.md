# Diabetes Prediction

## Project Overview

Diabetes Prediction is a Machine Learning classification project that predicts whether a person is likely to have diabetes based on various medical diagnostic features.

The project uses the Pima Indians Diabetes Dataset and applies machine learning techniques to analyze the data and make predictions.

## Objective

The main objective of this project is to build a Machine Learning model that can classify patients into two categories:

- 0 → Non-Diabetic
- 1 → Diabetic

## Dataset

The dataset is stored in `diabetes.csv`.

It contains medical and diagnostic information such as:

- Pregnancies
- Glucose
- Blood Pressure
- Skin Thickness
- Insulin
- BMI
- Diabetes Pedigree Function
- Age
- Outcome

## Project Workflow

1. Import the required libraries

6. Split the dataset into training and testing data

8. Evaluate the model
