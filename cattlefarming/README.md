# Cattle Farming Management System

A Django-based web application for managing cattle farming activities
with machine learning based prediction features.

## Features

- User authentication
- Cattle management
- Daily farming records
- Machine learning predictions
- Dashboard
- Data management

## Technologies Used

- Python
- Django
- HTML
- CSS
- JavaScript
- Machine Learning
- SQLite
