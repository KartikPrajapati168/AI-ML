# SONAR Rock vs Mine Prediction

## Project Overview

SONAR Rock vs Mine Prediction is a Machine Learning classification project that predicts whether an object detected using SONAR signals is a Rock or a Mine.

The project uses SONAR signal data and applies supervised Machine Learning techniques for binary classification.

## Objective

The main objective of this project is to classify SONAR signals into two categories:

- R → Rock
- M → Mine

## Dataset

The dataset contains SONAR signal measurements represented by numerical features.

Each row represents a SONAR signal observation and contains multiple numerical features followed by the target class.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Jupyter Notebook

## Project Workflow

1. Import required libraries
2. Load the SONAR dataset
3. Explore and understand the dataset
4. Separate features and target variable
5. Split the dataset into training and testing sets
6. Train the Machine Learning classification model
7. Evaluate model performance
8. Make predictions for new data

- `Copy_of_Rock_vs_Mine_Prediction.ipynb` — Copy of the project notebook
